# AIR-Bench
Arxiv: https://arxiv.org/html/2402.07729v1  
This is the AIR-Bench dataset download page.  
AIR-Bench encompasses two dimensions: foundation and chat benchmarks. 
The former consists of 19 tasks with approximately 19k single-choice questions.
The latter one contains 2k instances of open-ended question-and-answer data.   
For how to run AIR-Bench, Please refer to AIR-Bench github page(https://github.com/OFA-Sys/AIR-Bench)(will be public soon).
